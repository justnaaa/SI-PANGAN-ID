6. PENJELASAN MENDALAM CARA KERJA AI & MACHINE LEARNING DI SI-PANGAN-ID
====================================================================================================
Status Realisasi: 100% RIIL BERBASIS MODEL MATEMATIKA, BAPANAS & PIHPS METRO
Lokasi Kode     : src/ai/priceAdvisorEngine.js (Engine Rekomendasi Harga & Proyeksi 3 Hari)
                  src/ai/aiForecastAndSurplus.js (Engine Neraca Surplus/Defisit & AI Matching)
                  src/domain/sharedFoundation.js (Formula Kebutuhan Gizi & Social Scoring)

Aplikasi SI-PANGAN-ID mengintegrasikan 4 modul kecerdasan buatan dan machine learning analitis:

1. FAIR PRICE RECOMMENDATION ENGINE (KALIBRASI HARGA ADIL P2P):
   * Tujuan: Menghilangkan perangkap tengkulak dan menjaga inflasi pangan lokal.
   * Sumber Data: Benchmark riil PIHPS (Pusat Informasi Harga Pangan Strategis) dan Pasar Tradisional
     Kota Metro (Pasar Cendrawasih, Tejoagung, Kopindo) yang disimpan dalam LAMPUNG_MARKET_INTELLIGENCE.
   * Cara Kerja:
     - Mengambil harga batas bawah pengepul (P_pengepul) dan harga batas atas pasar retail (P_pasar).
     - Menghitung Nilai Tengah Berimbang (Equilibrium Point):
       P_rekomendasi = (P_pengepul + P_pasar) / 2
     - Menetapkan Koridor Aman:
       Safe_Min = P_pengepul * 1.25  (Produsen untung minimal 25% di atas tengkulak)
       Safe_Max = P_pasar * 0.85     (Konsumen hemat minimal 15% di bawah harga pasar kota)
     - Memberikan evaluasi real-time saat produsen menginput harga: "Harga Wajar & Menguntungkan",
       "Terlalu Murah (Rentan Merugi)", atau "Terlalu Mahal (Daya Beli Warga Rendah)".

2. AI SURPLUS-DEFICIT BALANCE & ALLOCATION ENGINE (NERACA PANGAN):
   * Tujuan: Deteksi dini ketimpangan pasokan pangan mikro RT 13 sebelum terjadi pembusukan sayur (food loss).
   * Parameter Input:
     - Pasokan Riil (S): Agregasi stok siap serap dari listing aktif seluruh produsen pekarangan.
     - Daya Serap Konsumsi (D): Kebutuhan mingguan 40 KK dihitung dari standar AKG Bapanas per jiwa.
   * Model Matematis:
     Diff = S - D
     Ambang Toleransi (Surplus Threshold): 5 Kg.
     - Jika Diff > +5 Kg  => Status SURPLUS (🔴 LEBIH / LUAPAN PASOKAN)
     - Jika Diff < 0 Kg   => Status DEFISIT (🟡 KURANG PASOKAN)
     - Jika 0 <= Diff <= 5=> Status SEIMBANG (🟢 PAS / OPTIMAL)
   * Aksi Keputusan AI (Matching Decision):
     - Saat SURPLUS: Sistem otomatis menyusun formula spillover ratio:
       Local_Absorption_% = (D / S) * 100%
       Spillover_B2B_%    = 100% - Local_Absorption_%
       AI langsung mengaktifkan tombol penyaluran B2B ke Dapur Makan Bergizi Gratis (MBG) & Koperasi.

3. AI SOCIAL VULNERABILITY SCORING (DSS PRIORITAS BANTUAN PANGAN):
   * Tujuan: Penentuan penerima subsidi selisih harga dan bantuan pangan darurat secara objektif.
   * Rumus Multi-Kriteria (Multi-Variable Weighted Scoring):
     Score = (W1 * Income_Index) + (W2 * Dependency_Ratio) + (W3 * Need_Satisfaction) + (W4 * Distance_Factor)
     Bobot:
     - Pendapatan Bulanan (Bobot 40%): Semakin rendah pendapatan, skor kerentanan semakin tinggi.
     - Rasio Tanggungan Jiwa (Bobot 30%): Jumlah anggota keluarga (familySize) per rupiah pendapatan.
     - Pemenuhan Kebutuhan Gizi (Bobot 20%): Defisit kalori/protein keluarga terhadap standar AKG.
     - Jarak Spasial ke Kebun (Bobot 10%): Aksesibilitas fisik keluarga terhadap lumbung pangan RT.
   * Output Klasifikasi:
     - Skor >= 75: RENTAN_PRIORITAS (Berhak atas subsidi pangan dan alokasi bantuan pertama).
     - Skor 50-74: WASPADA (Monitoring daya beli mingguan).
     - Skor < 50 : MANDIRI (Keluarga dengan ketahanan ekonomi kuat).

4. DEMAND FORECASTING & FOOD TURNOVER VELOCITY (PREDIKSI LAJU PENYERAPAN):
   * Model menghitung laju perputaran stok (*turnover velocity*) berbasis Moving Average dari riwayat
     transaksi belanja warga.
   * Semakin banyak transaksi yang terverifikasi (dari 50 transaksi aktif), tingkat keyakinan (*Confidence Level*)
     model meningkat secara matematis dari 94,6% hingga mencapai 99,4%.

7. ARSITEKTUR LAYER PREDIKSI AI (BERAPA LAYER YANG DIBUTUHKAN DARI DATA SAMPAI TAMPIL)
====================================================================================================
Untuk memproses data mentah di SI-PANGAN-ID hingga menghasilkan visualisasi ramalan di antarmuka pengguna,
sistem membutuhkan tepat **5 LAYER ARSITEKTUR (5-TIER PIPELINE)** yang bekerja secara berurutan dan terisolasi:

+--------------------------------------------------------------------------------------------------+
| LAYER 1: DATA INGESTION & STATE NORMALIZATION LAYER (Input Layer)                                 |
| - Mengekstraksi state mentah: window.appState.members (40 KK), listings (8 komoditas pekarangan),|
|   transactions (50 riwayat), dan demands (voting warga).                                         |
| - Menormalisasi tipe data: string ke numerik, membuang data demo/dummy, dan memvalidasi NIK/SID. |
+--------------------------------------------------------------------------------------------------+
                                               │
                                               ▼
+--------------------------------------------------------------------------------------------------+
| LAYER 2: STANDARDS & REFERENCE BENCHMARKING LAYER (Feature Engineering Layer)                     |
| - Menginjeksi standar acuan nasional & regional:                                                 |
|   * Standar AKG Bapanas: Beras 0.25 Kg/jiwa/hari, Sayur 0.10 Kg/jiwa/hari, Protein 0.08 Kg/hari. |
|   * Matriks Intelijen Pasar: Pengepul vs Retail Kota Metro (LAMPUNG_MARKET_INTELLIGENCE).       |
|   * Baseline Ambang Batas: SURPLUS_THRESHOLD_KG = 5 Kg.                                          |
+--------------------------------------------------------------------------------------------------+
                                               │
                                               ▼
+--------------------------------------------------------------------------------------------------+
| LAYER 3: ANALYTICAL INFERENCE & ALGORITHMIC COMPUTATION LAYER (AI/ML Core Engine)                 |
| - Eksekusi logika matematis & analitik:                                                          |
|   * Menghitung total kapasitas mingguan per komoditas: sum(weeklyCap).                           |
|   * Menghitung proyeksi kebutuhan warga: baseNeed3Days + votingDemand.                           |
|   * Menghitung diferensiasi neraca: Diff = Harvest - Demand.                                     |
|   * Menghitung rasio serapan lokal vs spillover eksternal.                                       |
|   * Menghitung confidence level model berdasarkan volume transaksi riil.                         |
+--------------------------------------------------------------------------------------------------+
                                               │
                                               ▼
+--------------------------------------------------------------------------------------------------+
| LAYER 4: ACCESS MATRIX, PRIVACY & FILTERING LAYER (Security & RBAC Enforcement)                  |
| - Memeriksa peran aktif pengguna (resolveEffectiveRole):                                         |
|   * PRODUSEN: AI memfilter list dan hanya menampilkan produk kebun miliknya (mode 'Fokus Kebun').|
|     Nama produsen lain di tabel disamarkan (masking: Ibu S., Pak H.) demi privasi kapasitas.     |
|   * KONSUMEN: Tab Analisis AI disembunyikan total agar tidak membingungkan warga pembeli.        |
|   * ADMIN: Seluruh data agregat 40 KK dan konsol simulator terbuka penuh tanpa masking.         |
+--------------------------------------------------------------------------------------------------+
                                               │
                                               ▼
+--------------------------------------------------------------------------------------------------+
| LAYER 5: PRESENTATION & REACTIVE DOM RENDERING LAYER (Output / View Layer)                       |
| - Mentransformasikan hasil komputasi ke elemen visual browser:                                   |
|   * Kartu Metrik: #surplusDisplayTotal (Kg/mgg), #surplusDisplayLocal, #surplusDisplayDiff.      |
|   * Status Badges: Merah (SURPLUS), Kuning (DEFISIT), Hijau (SEIMBANG).                          |
|   * Grafik Tren Harga 3 Hari: Merender Chart.js dengan kurva riil Bapanas vs Lapak.              |
|   * Generator WhatsApp MBG: Tombol aksi penyaluran 1 paket resume otomatis terisi data surplus.  |
+--------------------------------------------------------------------------------------------------+

Total: **5 Layer Komputasi**. Setiap layer berdiri sendiri (*loose coupling*), sehingga pengujian logika
matematis di Layer 3 dapat diuji 100% via unit test tanpa ketergantungan pada tampilan DOM (Layer 5).
